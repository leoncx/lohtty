The goal is to have a terminal compatible windows.

Write in rust with gpui library

The main feature:

[ ] Multiple tab
[ ] Split horizontal or vertical
[ ] Search text
[ ] UTF-8
[ ] Manage theme with default theme tokyo night
[ ] Manage background opacity
[ ] Manage ligatures font
[ ] Manage kitty graphics protocol
[ ] Can choose the shell (Powershell by default)
[ ] Manage title change
[ ] XTerm compatible
[ ] Mulitple OS supported: Windows main dev
